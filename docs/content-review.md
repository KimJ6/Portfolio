- Drilling: 성장감 목표, 전달받은 업그레이드 수치의 파기 속도 반영, 독립 판정 범위, 기본 조작을 보존했다. 반복을 줄이고 초기 개발 참여를 역할과 분리했다. 팀의 현재 개발·출시 상태는 미확인이므로 `unknown`; 사용 엔진 및 언어 역시 미확인으로 기술 목록을 비워 두고 확인된 구현 기법을 별도 필드에 기록했다. Steam 이미지의 실제 개인 구현 버전과의 일치 여부는 미확인이다.
- 렌더링 연구: 논문 첫 페이지의 초록에서 확인한 2×2 실험 설계, 평가 지표, 메인 스레드·GPU 시간 차이, 렌더 스레드 시간, 중간 부하에서의 프레임 안정성 결과를 보완했다. 기존 6.3~8.5%, 0.5% 미만의 수치 및 조건을 유지했다. 성능 차이의 내부 원인을 새로 단정하지 않았다. 게재 월 및 DOI를 추가하고 연구 종료 시점으로 사용되던 게재 연도는 제거했다. 전체 연구 종료 여부는 미확인으로 상태를 `unknown` 처리하되 논문 게재 사실은 유지한다. 이메일 및 연락처가 포함된 논문 첫 페이지 이미지는 배포 후보 ZIP에서 제외하고 논문 링크 및 서지 정보로 대체했다. 원본 v1과 원본 HTML ZIP은 변경하지 않았다.
- PrecisionTick: 기존 사례의 순서와 설정 일괄 적용, 잔차 보정, Drift·Jitter의 프로젝트 내 정의를 유지했다. 역할과 결과의 반복을 줄였다. 프로젝트 완료·운영 상태는 미확인이므로 `unknown` 처리했다. 반응형 UI는 별도의 구현 기법으로 분류했다.
- 이력서: 당시 기간 표기를 통일하고 프로젝트 참조를 유지했다. v1.2에서 학력 및 어학 정보는 삭제한다.

## 추가·변경 및 보류

- 프로필은 닉네임과 관심 직무/기술을 최신 사용자 지시에 맞춰 수정. AI 시대에 관한 일반적 견해는 이전 설계에 따라 생략했으며, 기획과 실행 제약을 함께 고려한다는 핵심 관점은 유지.
- 연구의 실험 조건, 정량 결과, 서지 정보는 KCI 초록 및 서지 정보를 확인해 추가. 전체 논문 본문 검증은 하지 못함. 특정 조건의 비교 결과로 한정.
- Drilling의 Steam 페이지는 상점 공개를 확인했으나 현재 출시 여부는 확정하지 못함. `status: in-progress`는 원문의 초기 개발 참여 및 확인된 상점 정보에 따른 잠정 분류이며 개인 참여가 계속된다는 의미가 아님. 엔진·언어 정보는 원문에 없으므로 기술 필드에는 확인된 구현 기법만 기재. 엔진·언어·참여 기간과 현재 상태는 배포 전 확인 필요.
- OverTheHorizon의 구현 현황·플레이 테스트·성능 측정은 확인하지 못해 설계 중심으로 보존. 설계 문서 링크도 접근 여부 검증 필요.
- PrecisionTick의 `completed`는 원문에 서술된 앱 및 기능 구현에 대한 잠정 분류. 현재 운영 여부, 실제 시간 오차 측정값, 모바일 호환 범위는 미확인. 링크의 공개 접근성 확인 필요.
- 미확인 프로젝트 기간은 생략. PinShift는 이전 설계에서 추가 후보에 불과하므로 포함하지 않음.
- 논문 서지 정보는 프로젝트의 `publication` 확장 필드 한 곳에서 관리. 상세 페이지 및 이력서에서 출력 시 참조. 관련 논문 URL은 `links`에서 참조.
- 이미지 출처는 기존 자료를 유지. Steam 외부 이미지의 이용 조건 및 접근성 확인 필요. 논문 첫 페이지는 실제 공개 권한 검토 후 사이트에서 사용.
- 배포 전 이력서의 공개 범위 확인. v1.2에서 학력 및 어학 정보 제외. 전화번호, 주소, 학번, 불필요한 개인 정보는 포함하지 않음.

## v1.3 PinShift 추가 (2026-11-24)

첨부된 PinShift 2D 오픈소스 미니 프로젝트 보고서 1~4페이지와 GitHub README를 근거로 `content/projects/pin-shift.md`를 추가했다. 게임 규칙, 물리와 표현의 분리, CSV 설정 관리, 라운드 전환·끼임 예외 처리, API 실험 및 기본 규칙 테스트를 압축했다. AI 보조 구현 범위를 명시했으며 Box2D 원본 수정, 성능 개선 수치, 게임성 검증을 주장하지 않는다. 개발 기간과 데모 공개 접근성은 미확인이다. 실제 게임 스크린샷이 제공되지 않아 대표 이미지는 생략했다. 보고서 원본은 개인정보 보호를 위해 포함하지 않는다.

## v1.6 사용자 제공 정보 반영 및 공개 문구 검수 (2026-11-24)

- Drilling: 사용자가 Unity 기반 동아리 2D 채굴 탐험 게임임을 명시하고, 물리 충돌과 타일 파괴 판정의 분리 제안 및 별도 AABB를 이용한 구현을 설명했다. 이에 Unity 기술 정보, 설계 판단, 구현 방법과 목표를 본문·요약·이력서에 반영했다. 이전의 엔진 미확인 기록은 당시의 검수 이력이며 Unity에 대해서는 해소되었다. 언어, 참여 기간, 최종 버전의 개인 구현 반영 여부는 추가로 추정하지 않았다.
- Drilling의 Steam 공개 이미지 캡션은 게임플레이 화면이라는 설명만 남겼다. 최종 공개 화면이 개인 초기 구현과 같은 버전인지는 확인되지 않았다는 기록은 이 관리 문서에만 남긴다.
- 전체 프로젝트 및 프로필의 공개 문구를 검수하고 OverTheHorizon의 작성 방식에 관한 안내 문장을 제거했다. 실제 개발 상태, 역할, 연구의 실험 조건 및 결과의 적용 한계는 유지했다. 다른 프로젝트의 콘텐츠는 변경하지 않았다.

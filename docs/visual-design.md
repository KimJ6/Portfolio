# 시각적 강조 및 테마 규격 v1.0 (웹사이트 v1.7)

[요구사항 및 작성 원칙](requirements.md), [정보 구조](information-architecture.md), [Markdown 서식 규격](markdown-specification.md)의 하위 표현 규격이다. 콘텐츠의 사실, 인과관계, 정렬 순서와 이력서 PDF의 디자인은 변경하지 않는다.

## 색상

| 역할 | 라이트 | 다크 |
| --- | --- | --- |
| 기본 배경 | #FFFFFF | #000000 |
| 기본 본문 및 제목 | #000000 | #FFFFFF |
| 보조 정보와 구분선 | #757575 | #757575 |
| 강조 | #BE2426 | #BE2426 |

사용자가 확정한 빨간색은 두 테마에서 동일하게 적용한다. 흰 배경 대비 약 6.05:1, 검정 배경 대비 약 3.47:1로, 검정 배경의 작은 빨간 글씨는 WCAG AA 일반 텍스트 대비 4.5:1을 충족하지 않는다. 큰 텍스트 기준 3:1은 충족한다. 색상 고정 요청을 우선 적용하며 전체 WCAG AA 적합성을 주장하지 않는다. 회색 대비는 흰 배경 약 4.61:1, 검정 배경 약 4.56:1이다.

## 표현 책임

| 대상 | 표현 |
| --- | --- |
| 슬로건 | `headline_emphasis`에서 지정한 핵심 개념만 빨간색; 조사, 서술어는 본문색 |
| 메인 프로젝트 요약 | 문제 정의, 역할 및 기여, 주요 결과의 항목명만 빨간색 |
| 상세 페이지 | 문제 정의, 역할 및 기여, 설계 및 구현, 플레이 및 실행 구조 설계, 결과 및 검증, 인사이트 및 한계에 해당하는 H2만 빨간색 |
| 프로젝트 번호 | 빨간색 |
| 프로젝트명, 부제, 하위 제목, 설명 문단 | 기본 본문색 |
| 기술 태그 | 투명 배경, 본문색, 고정 회색 테두리 |
| 상태, 분류, 캡션 | 고정 회색 |
| 목차, 관련 자료, 다른 프로젝트 | 기본 본문색 |
| 링크 | 평상시 본문색, 밑줄 또는 명시적 탐색 구조; 호버 및 포커스에 강조색 사용 |
| 캐러셀 | 활성 표시 빨간색과 외곽선, 비활성 표시 회색 |
| 이미지, 그래프, 결과물 | 원본 색상 유지 |

## 관리 원칙

- D-01: 테마 전환 시 기본 흑백 배경과 본문색만 반전한다. 흑백에 의존하는 UI도 같은 변수로 반전한다.
- D-02: 회색 및 빨간색의 값은 고정한다.
- D-03: 개별 문서에 CSS나 색상값을 넣지 않는다. 공통 템플릿, 빌드 및 CSS가 표현을 책임진다.
- D-04: 빨간색은 핵심 가치, 역량 증명 구조, 탐색·상호작용 상태에 한정한다.
- D-05: 본문 단어를 자동으로 강조하지 않는다.
- D-06: 상위 섹션의 정보 책임에 따라 강조한다. 모든 H2를 일괄 강조하지 않는다.
- D-07: H3, H4 및 본문은 기본색을 유지한다.
- D-08: 보조 정보는 회색을 사용한다.
- D-09: 회색 배경 면 대신 기본 배경, 여백, 고정 회색 구분선을 사용한다.
- D-10: 이미지의 색상을 반전하거나 필터링하지 않는다.
- D-11: 제목 계층, 굵기, 밑줄, 포커스 외곽선 등 비색상 단서도 유지한다.
- D-12: 강조색이나 적용 영역 변경 전 정보 책임과 대비를 검토한다.

빌드에서 `headline_emphasis`의 자료형, 중복, 포함 여부를 검증하고 Markdown H2의 정보 책임에 맞는 공통 클래스를 지정한다. PDF 템플릿과 기존 프로젝트 문서는 그대로 유지한다.

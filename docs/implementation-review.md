# 웹사이트 구현 및 검증 기록

작성일: 2026-11-24

## 구현 결정

- v1.1의 콘텐츠 Markdown 6개를 바이트 단위로 보존했다. 기존 이미지 3개를 유지했다.
- 기존 HTML의 흰색/검정 기반 색상, 빨간 강조색, 큰 제목, 대표 프로젝트 캐러셀, 테마 전환, 이미지 확대를 참고했다. 기존 마크업을 그대로 복제하지 않고 메인/상세 페이지 구조에 맞춘 공통 템플릿을 사용한다.
- Python 정적 생성기(Jinja2, markdown-it-py, PyYAML)와 WeasyPrint를 선택했다. 프레임워크 없이 단일 빌드에서 정적 HTML과 PDF를 함께 생성하기 위함이다.
- GitHub Pages의 하위 경로를 고려하여 내부 URL은 상대 경로로 생성한다. `.nojekyll`을 포함한다.
- `unknown` 상태는 표시하지 않으며 Drilling의 구현 기법은 기술 스택으로 분류하지 않는다. 외부 이미지 오류 시 대체 안내를 표시한다.
- `experiences.md` 등 현 단계에서 채택하지 않은 선택 콘텐츠 유형은 구현하지 않았다.

## 웹사이트 구현 v1.1 수정 및 재검증 (2026-11-24)

- 사용자 지정 슬로건 `실행 계층에서 일하고,` / `플레이 경험을 지향한다.`를 profile.md의 단일 문자열에 줄바꿈으로 저장. 프로젝트 Markdown 4개, 이력서 Markdown, 이미지 3개는 v1.0 소스와 바이트 단위로 일치한다.
- 메인 상단의 여백과 이미지 높이, 모바일 정보 밀도를 조정. 캐러셀에는 기존 상태·참여·성과 메타데이터와 주요 결과를 출력하며, 대표 프로젝트의 동일 이미지가 목록에 반복되지 않게 한다. 상세 페이지에서는 이미지와 담당 역할을 명시한다.
- 캐러셀 전환의 라이브 안내, 조작 버튼 영역, 이미지 오류 대체 정보를 보완했다.
- 이력서에서 알려진 기간 및 배포 URL을 표시하도록 지원하고 기술 목록 반복을 줄였다. 확인되지 않은 기간 및 주소는 표시하지 않는다. Pages workflow는 configure-pages의 base_url을 빌드에 전달하도록 설정했다.
- 상위 요구사항을 저장소용 Markdown으로 변환하고 정보 구조 및 서식 규격, 공통 템플릿을 추가했다. 이전 보정 기록은 이력으로 유지한다.
- 빌드 검사에 날짜, 주요 자료형, 표시 순서, 제목 계층, 필수 H2 및 빈 섹션, 논문 기본 메타데이터, 중복 HTML ID, 내부 앵커 검사를 추가했다.

재빌드 성공: HTML 5개, PDF 1개. 기존 원본과 비교하여 슬로건 이외의 콘텐츠 변경 없음. Chromium 메모리 내 렌더링 5페이지 × 4개 너비(1440/768/390/320px), 캐러셀, 테마 전환, 이미지 확대 및 Escape 닫기 통과. 실제 URL을 사용하는 HTTP 탐색과 테마 지속성, 외부 이미지 및 링크, 원격 GitHub Actions 실행은 미검증. PDF A4 1페이지, 링크 9개, 한글 렌더링 확인. 테스트용 URL을 지정한 경우 PDF 링크 생성 확인 후 테스트 주소를 제거하고 재빌드했다. 잘못된 날짜, 중복 순서, 필수 섹션 누락, 제목 계층 건너뛰기를 거부하는 테스트 통과.

남은 사항: 실제 배포, 외부 자료 접근 및 이미지 권한, 미확인 프로젝트 기간과 기술, 최신 구현 범위, 이력서 공개 범위 확인. 과제 제출 TXT는 실제 URL 검증 후 작성한다.

## 웹사이트 v1.2 수정 및 검증 (2026-11-24)

사용자 지정 사항: 학력·어학 삭제, 최초 HTML 순서 복원. 프로필의 전공 표현과 이력서 원본의 학력·어학 본문을 제거했다. 프로젝트 표시 순서는 렌더링 연구, Drilling, OverTheHorizon, PrecisionTick Metronome이며 이력서는 프로젝트 ID로 포함 여부만 지정하고 `order`를 공유한다. 관리 문서와 서식을 갱신했다. 기존 프로젝트 문서는 `order` 이외 바이트 동일, 슬로건·이미지·CSS·JS·웹 페이지 템플릿 및 배포 워크플로 보존. 재빌드 5 HTML, 내부 링크/앵커 검사, 캐러셀·목록·상세 탐색·PDF의 순서 대조, 학력 및 어학 데이터 삭제 확인, A4 1페이지 PDF 시각 검토 및 텍스트 검사 통과. 실제 배포와 외부 링크 검증은 미수행.

## v1.3 PinShift 추가 (2026-11-24)

PinShift를 네 번째에 추가하고 PrecisionTick의 order를 5로 변경했다. 기존 프로젝트 본문 및 요약, 프로필, 디자인, 배포 설정은 보존했다. 이력서에 PinShift 참조를 추가했다. HTML 6개 및 이력서 PDF 재빌드, 내부 링크·앵커 검증, 캐러셀·목록·상세 탐색·이력서의 정렬 검사, 기존 콘텐츠 바이트 비교(PrecisionTick의 order 제외), 학력·어학 제외 검사 통과. PDF는 A4 1페이지로 시각 검토했다. 브라우저 재검사는 URL 접근 제한 및 시간 초과로 완료하지 못했으며, 외부 링크 및 원격 배포는 미검증이다.

## v1.4 이력서 사용 기술 배치 수정 (2026-11-24)

독립 기술 역량 섹션을 제거하고 각 프로젝트 설명 아래 기존 `technologies` 값을 작은 글씨로 출력한다. 빈 목록(Drilling)은 생략한다. 콘텐츠 원본 및 기존 웹 페이지의 HTML/CSS/JS와 이미지, 순서, 슬로건, 배포 설정은 변경하지 않았다. 6개 HTML 및 PDF 재빌드, 내부 링크 검사, 이전 정적 출력물과 비교(PDF 제외 바이트 동일), PDF A4 1페이지, 사용 기술 4개 행과 순서, 기존 PDF 링크 일치, 학력 및 어학 제외, PDF 렌더링 육안 확인 통과. 외부 링크 및 원격 배포는 이번 변경 범위에 포함하지 않는다.
